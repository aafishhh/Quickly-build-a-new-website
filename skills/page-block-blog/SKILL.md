# 页面块区模板：Blog（列表页 + 文章页）

## Overview

「页面块区 skill」家族按页面类型逐类覆盖**单页内部的块区结构 + UI**（这是 mvp-scoping 明确让渡给本家族的职责）。每个页面类型一个 skill：首页、Blog、About、工作台……

本 skill 覆盖 **Blog 两类页面**：
1. **Blog 列表页**（`/blog/`）：博客入口，文章卡片聚合
2. **单篇文章页**（`/blog/<slug>/`）：单篇内容阅读页

块区结构**以真实站 `trendtrackpromocode.com` 为参考源**提炼（抓取分析了它的 `/blog/` 和一篇长文），已做成**通用模板**——块区顺序和职责不绑定品牌，可套用到任意网站，只替换品牌/文案/内容即可。

**两个重要边界**：
1. **产品定制组件不固化**：Sticky 导航、页脚是**产品级组件**——不同产品栏目、CTA、品牌文案、法律链接都不同，本 skill **只标记它们的位置**，不固化内容（具体由产品/首页块区模板定）
2. **SEO 内容规则不归本 skill**：H1 标题、导语、正文的**写法**涉及 SEO（关键词/密度/结构），由**独立的 SEO 内容规则 skill** 管辖；本 skill 只管「这个块存在、在哪、什么顺序」，**不管写什么**

**与上层的衔接**：
- 输入：`mvp-scoping` 的页面清单（本文档细化 Blog 页这一类的块区）
- 输出：块区结构可直接交给 `tool-site-foundation`（技术实现）或开发
- 本 skill 只定「块区长什么样（位置/顺序/作用）」，不写代码、不定 SEO 内容

## 参考站实际结构（trendtrackpromocode.com）

以下是从该站 `/blog/` 与单篇文章页**实际抓取**的块区顺序，作为模板依据：

### Blog 列表页（/blog/）实际块区
```
┌─ sticky 导航（产品定制占位）─────────────────────┐
│  Logo + [栏目...] + CTA（由产品定）               │
├───────────────────────────────────────────────────┤
│ Hero 标题区（居中）                                │
│  标题「TrendTrack Blog」+ 副标题（品牌博客定位）      │
├───────────────────────────────────────────────────┤
│ 文章卡片列表（网格 gap-6）                          │
│  每一张卡片 = 日期 + 标题 + 摘要                    │
│  （6 张 / 一屏）                                   │
├───────────────────────────────────────────────────┤
│ 页脚（产品定制占位）                                │
│  品牌简介 + 栏目列 + 版权 + 法律链接（由产品定）       │
└───────────────────────────────────────────────────┘
```

### 单篇文章页（/blog/<slug>/）实际块区
```
┌─ sticky 导航（产品定制占位）─────────────────────┐
├───────────────────────────────────────────────────┤
│ 元信息行：日期 · 阅读时间（如 Nov 6, 2026 · 17 min read）│
│ H1 标题（位置；写法归 SEO 内容规则）                │
│ 导语（位置；文案归 SEO 内容规则）                   │
│ 封面大图（圆角，居中）                             │
├───────────────────────────────────────────────────┤
│ 正文（H2→H3→列表/表格/内链；内容归 SEO 内容规则）    │
├───────────────────────────────────────────────────┤
│ Related Posts（相关文章卡片 + 「View All Posts」链接）│
│ Share（分享按钮）                                  │
├───────────────────────────────────────────────────┤
│ 页脚（产品定制占位，同列表页）                      │
└───────────────────────────────────────────────────┘
```

## Step 1: Blog 列表页块区模板（通用）

给任意网站做 `/blog/`，套用这个块区顺序：

| # | 块区 | 作用 | 通用化要点 |
|---|---|---|---|
| 1 | **Sticky 导航（产品定制占位）** | 全站入口 | **只标位置**：复用产品导航组件，栏目/CTA 由产品自身定（不同产品不同），本 skill 不固化 |
| 2 | **Hero 标题区**（居中 `max-w-3xl`） | 确立博客定位 | 标题=「{品牌} Blog」；副标题=一句话说明博客是干嘛的（品牌博客/指南/评测…） |
| 3 | **文章卡片列表** | 内容聚合入口 | 网格布局（`gap-6`），**每张卡片**：日期 + 标题 + 摘要。可选添加：缩略图/封面图、分类、阅读时间、作者 |
| 4 | **页脚（产品定制占位）** | 全站收尾 | **只标位置**：复用产品页脚（品牌简介/栏目列/版权/法律链接因产品而异），本 skill 不固化 |

**定制点**（换品牌/换主题时改这 4 处）：
- 卡片字段：最小是「日期+标题+摘要」；要更丰富就加缩略图/分类/阅读时间/作者
- 网格密度：一屏放几张（示例 6 张），决定卡片信息量
- 是否分页/「加载更多」：文章多时加
- **Hero/卡片文案**：属于 SEO 内容规则（标题/导语写法另由 SEO skill 定）

## Step 2: 单篇文章页块区模板（通用）

给任意网站做 `/blog/<slug>/`，套用这个块区顺序：

| # | 块区 | 作用 | 通用化要点 |
|---|---|---|---|
| 1 | **Sticky 导航（产品定制占位）** | 全站入口 | **只标位置**：复用产品导航组件，栏目/CTA 产品自定 |
| 2 | **元信息行** | 阅读前信息 | `日期 · 阅读时间` 并排（示例：`Nov 6, 2026 · 17 min read`）。可加：作者、分类 |
| 3 | **H1 标题** | 文章标题 | **只标位置**：唯一 H1 存在此处；标题怎么写（关键词等）归 SEO 内容规则 skill |
| 4 | **导语** | 摘要/开局 | **只标位置**：副标题或摘要段落；文案写法归 SEO 内容规则 skill |
| 5 | **封面大图** | 视觉入口 | 圆角、居中、宽幅（示例 `lg:max-w-[900px]`） |
| 6 | **正文** | 核心内容 | **只标结构位置**：`H2 → H3 → 列表/表格/内链` 层级；长文可按需加 TOC/目录。正文内容/关键词密度归 SEO 内容规则 skill |
| 7 | **Related Posts** | 留住读者 | 相关文章卡片（缩略图+标题）+「View All Posts →」链接 |
| 8 | **Share** | 传播 | 文章底分享按钮（可选） |
| 9 | **页脚（产品定制占位）** | 全站收尾 | **只标位置**：复用产品页脚，内容产品自定 |

**定制点**（块区层面可调的项）：
- 元信息行：必含「日期+阅读时间」；作者/分类按需
- 正文是否加 TOC：长文（>10min 阅读）建议加目录，短文可不要
- Related：可标题卡片 + 「View All」链接；也可只列链接
- 是否加 CTA 区：内容营销型博客常在 Related 前插入产品/订阅 CTA（参考站就插了品牌促销 CTA）
- **H1/导语/正文文案**：不在此定，由 SEO 内容规则 skill 管（关键词/字数/结构密度）

## 复用共享组件

- **导航 / 页脚**：**产品定制占位**——应在产品级（由 `tool-site-foundation` 或首页块区模板）统一，博客页只引用其位置，**不在本 skill 固化内容**（不同产品导航栏目、页脚链接都不同）
- **文章卡片**：列表页卡片与 Related 卡片用同一套卡片样式，保持一致性

## 与上层衔接

- **输入**：`mvp-scoping` 的页面清单已包含 Blog 页 → 本 skill 细化其块区
- **待补**：Blog 之外的基础页块区（About/Contact/Privacy/Terms）是「页面块区 skill 家族」的**第一批通用模板**（高度同构、模板化），可单独立 skill 做
- **输出**：块区结构交给 `tool-site-foundation` / 开发实现

## 注意事项

- **只定块区，不写代码**：本 skill 给「长什么样、什么顺序、放什么」，实现交给 tech skill
- **导航/页脚不做成博客专属**：产品级组件，产品自定内容；博客只标位置
- **SEO 内容不在本 skill**：H1/导语/正文的写法（关键词/密度/结构）由独立 SEO 内容规则 skill 管辖，本 skill 只定块区存在与顺序
- **卡片一致性**：列表页卡片 = Related 卡片同一套样式
- **诚实标注**：参考站是内容营销型博客（带了较多促销 CTA），做纯内容/工具站博客时可去掉那些 CTA——按自己网站定位取舍
- 与 `git-worktree-isolation` 配合：博客模块在独立 worktree/分支开发
