# 博客 SEO 写作规范

> 本 skill 由用户完整调教的固定标准整理，作为所有博客写作的强制规范。**顺序不能乱，校验不过不许交付。**

## 一、写作流程（顺序不能乱）

1. **关键词确认**：以用户给的主关键词为准，补充 3–5 个变体/长尾（同义改写、问题式、带修饰词）。
2. **防自我蚕食**：动笔前先确认站内没有另一篇在打同一个关键词；有就改为**更新/扩写旧文**，或**换差异化角度**并明确主从分工（一篇一词）。两篇相近时：**主篇**拿内链和曝光，**从篇**链向主篇。
3. **竞品研究**：抓 SERP 前 5 名，逐条记录——TDK、H1/H2 结构、内容覆盖点、字数区间、内容形式。
   - 总结：他们**共同覆盖了什么**（必须写）、**谁独有的亮点**（可借鉴）、**大家没写好的**（差异化机会）。
4. **TDK 方案**：直接给一版，写清策略思路即可，**不用做多版本选择**。
   - Title：50–60 字符，核心关键词前置（前 30 字符内出现）
   - Description：150–160 字符，「是什么 + 用户好处 + 行动点」，不堆砌关键词
5. **用户确认 TDK 后再写正文**。

## 二、正文结构规范

- H1 只有一个，与 Title 一致；H2 按搜索意图组织，长尾词自然融入小标题
- 开头 100 字内回答核心问题（匹配精选摘要格式），再展开
- 竞品共同覆盖的板块必须覆盖；至少 1 个差异化板块（对比表 / 步骤清单 / 数据 / FAQ）
- 结尾放 FAQ 段：3–5 个真实搜索问题，每条答案 ≥70 字符、不以冒号结尾；
  **FAQ 问题必须和页面可见文本逐字一致，否则富摘要会失效**
- 数据必须有出处；**无法核实的数字宁可不写**；日期用动态变量，不写死月份

## 三、关键词密度

- 主关键词密度 1%–2%（按正文总词数算，写完报出实际值和出现次数）
- **首段、至少 1 个 H2、结尾段各出现 1 次**；任何**单段超过 3 次**就算堆砌，必须改写
- 不许为凑密度硬塞：以读起来自然为前提，优先用变体/同义词分散

## 四、内链规范

- 每篇 2–4 条站内链接，锚文本用目标页主题词（不用 "click here"）
- **必做：1 条链向首页，锚文本就是品牌名**（例：`<a href="/">BrandName</a>`）
- 其余链向相关主题文或转化页；所有内链指向**真实存在的 URL**，发前逐一验证
- 发新文时反查：2–3 篇**高权重旧文**补链到新文

## 五、URL / 图片 / 技术规范

- **slug**：发文前**定死、上线后永不改**；全小写英文 + 连字符，2–5 个词，含核心关键词，去掉虚词
- **图片**：文件名含关键词（不是 IMG_0042.jpg）；每张图 `alt` = 人类可读描述，自然含变体词；压缩为 **WebP、单图 ≤200KB**；`<img>` 必须**带宽高**（`width`/`height`，防布局抖动）
- **Open Graph**：`og:title` / `og:description` / `og:image` 齐全（og:image **1200×630**）
- **外链**：引用数据/声明时链权威原始出处（1–2 条，`rel="nofollow"`），**只链出不做友链交换**
- **最后更新**：页面展示「最后更新」日期，与结构化数据 `dateModified` 一致；旧文**超 6–12 个月定期复查翻新**

## 六、发布后 24 小时内

- 提交 **Google Search Console**：新 URL 检查 → 请求编入索引
- 确认 **sitemap 已更新**、页面可被发现

## 七、交付与验证

- 交付时列出：TDK 及字符数、H2 大纲、关键词密度（出现次数/总词数/百分比）、内链清单（锚文本→URL）、**slug 与图片 alt 清单**
- **任何校验不过（字符数、密度、内链 404）都停下来改，不许带病交付**
- 不确定的事实先问用户，不许编造

## 与页面块区 skill 的衔接

- `page-block-blog` 定「博客页的块区结构」（元信息行/H1/导语/封面/正文/Related/Share 的位置与顺序）
- 本 skill 定「**这些块里写什么**」——H1 的写法、导语的写法、正文的结构与密度、内链规则、slug/图片/发布后动作
- 即：**块区 skill 给骨架（放哪），本 skill 给内容规则（写什么）**，二者配套使用

## 注意防蚕食

- 写新文前**先站内搜索是否已有一篇打同一关键词**；有则转更新/扩写，或换角度定主从（一篇一词）
- 主篇拿内链曝光，从篇链向主篇，避免两篇互抢排名

## 注意事项

- **流程顺序不可乱**：关键词 → **防蚕食** → 竞品 → TDK →（用户确认）→ 正文
- **TDK 一版即可**：不做多版本选择，写清策略思路
- **硬校验不可跳过**：字符数/密度/内链/图片/slug 逐一验证，不过就停下改
- **技术规范必做**：slug 定死不改、图片 WebP+alt+带宽、OG 齐全、外链 nofollow、最后更新与 dateModified 一致
- **发布后 24h 必做**：GSC 提交索引 + 确认 sitemap
- **诚实**：数据有出处；无法核实的宁可不写；不确定的先问
- 与 `git-worktree-isolation` 配合：博客写作在独立 worktree/分支
